# Architecture

The portfolio is a Vite + React + TypeScript application.

## Key Areas

- `src/components/`: page sections such as hero, about, work, research, contact, and footer
- `src/components/canvas/`: Three.js visual components
- `src/assets/`: project screenshots, icons, technology logos, and media
- `src/constants/`: structured project, experience, technology, and research content
- `public/`: static files, papers, resume, and 3D model assets

## Deployment

The site is deployed on Vercel. The production build is generated with:

```bash
npm run build
```
